PORTFOLIO — INSCRIPTIONS ET ESPACE D'ADMINISTRATION

Le formulaire, l'API et l'administration sont dans le depot Portefolio et doivent
etre deployes ensemble sur Vercel. L'administration est accessible sur
/admin.html et communique avec /api/admin sur le meme domaine.

La configuration Supabase, les variables d'environnement requises et les tests
de deploiement sont documentes dans README.md. Executer schema.sql une fois
dans Supabase > SQL Editor avant de tester les inscriptions.

Ce projet utilise Supabase et, en option, Resend pour les notifications par
e-mail. FormSubmit n'est pas utilise par le code actuel.

Le depot GitHub admin-portefolio est distinct ; il n'est pas necessaire pour
l'architecture actuelle. Ne pas deployer l'admin sur un autre domaine sans
adapter l'authentification et la configuration des cookies.
